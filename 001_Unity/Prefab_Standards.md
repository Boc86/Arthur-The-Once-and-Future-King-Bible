# Prefab Standards

## Purpose

Ensure consistent Unity assets.

---

# Player Prefab

Required:

- Transform
- Character Controller
- Player Controller
- Health Component
- Audio Source

---

# Enemy Prefab

Required:

- Transform
- Enemy Controller
- AI Brain
- Health Component
- Collider

---

# Naming

Examples:

Player_Arthur

Enemy_Bandit

Boss_Mordred

Weapon_Excalibur
