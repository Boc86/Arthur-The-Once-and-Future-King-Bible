# Vertical Slice Specification

## Goal

Create a complete small playable section.

---

# Required Features

Player:

- Arthur controller
- Combat
- Abilities

World:

- One playable region
- Exploration

Enemies:

- Three enemy types
- One boss

Loot:

- Weapons
- Armour
- Rewards

Systems:

- XP
- Level progression
- Save/load

UI:

- HUD
- Inventory
