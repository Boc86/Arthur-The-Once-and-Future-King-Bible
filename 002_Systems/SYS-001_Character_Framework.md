# Arthur: The Once and Future King

# SYS-001 Character Framework

Version 0.1

---

# 1. Purpose

The Character Framework defines the foundation for every playable character in Arthur: The Once and Future King.

This system supports:

- Arthur Pendragon
- Knights of the Round Table
- Future playable legends
- Temporary allies
- NPC heroes
- Enemy champions

The framework must allow every character to feel unique while sharing common systems.

---

# 2. Design Pillars Supported

This system supports:

✓ Every Knight Is A Unique Fantasy

✓ Combat Is Simple, Deep And Rewarding

✓ Data Before Code

✓ Loot Creates Possibilities

✓ The World Must Remember

They are legends.

A character is defined by:

```

↓
```

# 8. Character Identity System

Each character has three identity layers.

---

# Layer 1: Combat Identity

How the character fights.

Examples:

Arthur:

Balanced warrior king.

---

Merlin:

Arcane battlefield controller.

---

Lancelot:

High mobility duelist.

---

# Layer 2: Mechanical Identity

Unique gameplay mechanics.

Examples:

Arthur:

Royal Command.

Can empower allies.

---

Gawain:

Sun's Champion.

Stronger during daytime events.

---

Mordred:

Corrupted Legacy.

Trades health for power.

---

# Layer 3: Narrative Identity

The character's role in the legend.

Includes:

- Personal quests
- Dialogue
- Relationships
- Lore entries
