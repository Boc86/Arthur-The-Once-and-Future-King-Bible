# Arthur: The Once and Future King

# SYS-031 Combat Ability & Buildcraft System

Version 0.1

---

# 1. Purpose

This document defines the combat experience and character build system.

Combat must be:

- Easy to understand
- Difficult to master
- Responsive
- Rewarding
- Deep enough for long-term replay

The player should be able to create unique versions of every knight.

---

# 2. Core Combat Philosophy

The core principle:

> A knight is defined by how they fight.

Every character must feel mechanically different.

---

# 3. Combat Design Goals

Combat should provide:

```
Impact

Choice

Skill Expression

Progression
```
