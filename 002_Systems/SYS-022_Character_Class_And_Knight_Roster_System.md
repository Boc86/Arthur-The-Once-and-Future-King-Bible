# Arthur: The Once and Future King

# SYS-022 Character Class & Knight Roster System

Version 0.1

---

# 1. Purpose

The Character Class and Knight Roster System defines the playable heroes of Arthur: The Once and Future King.

The system establishes:

- Playable characters
- Class identities
- Unique combat styles
- Character progression
- Knight recruitment
- Individual stories
- Unique abilities

---

# 2. Core Philosophy

The core principle:

> The Round Table is not a collection of warriors. It is a collection of legends.

Every playable character must feel like:

- A different fantasy
- A different playstyle
- A different story

---

# 3. Design Pillars Supported

✓ Every Knight Feels Unique

✓ Combat Is Simple, Deep And Rewarding

✓ Restore The Legend

✓ Become The King

✓ Every Run Creates A Story
