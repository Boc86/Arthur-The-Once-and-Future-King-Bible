# Arthur: The Once and Future King

# SYS-027 Player Experience & Game Loop System

Version 0.1

---

# 1. Purpose

This document defines the player's moment-to-moment experience.

It describes:

- What the player does
- Why they continue playing
- How progression feels
- How each run creates a legend

---

# 2. Core Player Fantasy

The player fantasy:

> Become Arthur Pendragon, unite Britain, raise the Knights of the Round Table, and reclaim the throne through countless battles, deaths, and rebirths.

---

# 3. Core Emotional Goals

The player should feel:

```
Powerful

Curious

Victorious

Challenged

Responsible

Legendary
```

---

# 4. Primary Game Loop

The core loop:

```
Enter Britain

↓

Explore Procedural Region

↓

Fight Enemies

↓

Gain Experience

↓

Find Loot

↓

Make Choices

↓

Defeat Boss

↓

Progress Story

↓

Die

↓

Return To Camelot

↓

Strengthen Kingdom

↓

Begin Again
```
